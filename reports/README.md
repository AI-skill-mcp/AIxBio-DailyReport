# 每日简报档案

首期为 [2026-10-16](2026/10/2026-10-16.md)，收录3条来源核验通过的真实进展。历史对话中的新闻未被直接回填，基础技术知识收录在 `knowledge/technologies/`，并在网站上与每日新闻分开呈现。

每期唯一编辑源为 `reports/YYYY/MM/YYYY-MM-DD.json`。同名 Markdown 由 `pnpm generate` 确定性生成，不手工修改。

新建记录先使用 `status: "draft"`。完成一手来源与日期核验后再改为 `published`；已发布日报只允许 1–5 条真实且核验通过的内容，无需为了五条而填充。JSON、Markdown、索引一起提交到 PR。完整格式及校验规则见 [内容指南](../docs/content.md)。
